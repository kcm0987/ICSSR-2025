# SpamSpotterElite: "Identifying Spam, Protecting Your Messages"

This repository contains the implementation and supporting materials for the research paper titled:

**SpamSpotterElite: Identifying Spam, Protecting Your Messages**  
Accepted at the **Indian Council of Social Science Research (ICSSR) 2025**.

This work presents an efficient spam detection system using the **Multinomial Naive Bayes** algorithm. Our approach is optimized for performance on text-based messaging data, particularly email and SMS datasets. The model is lightweight, interpretable, and well-suited for real-world deployment in communication platforms.

## Abstract

This research introduces *SpamSpotterElite*, a spam classification system utilizing the **Multinomial Naive Bayes** model. By leveraging the probabilistic nature of this algorithm, combined with preprocessing techniques such as TF-IDF vectorization, we achieve reliable classification of spam and ham messages. The model was trained and evaluated using the **SMS Spam Collection** dataset, yielding high accuracy and low false positive rates. Its efficiency makes it suitable for both academic research and production environments.

---

## Features

- Text preprocessing (cleaning, normalization, stopword removal)
- Feature extraction using TF-IDF vectorization
- Multinomial Naive Bayes classification
- Evaluation using Accuracy, Precision, Recall, F1-Score
- Visualization: Confusion Matrix and ROC Curve
- Lightweight and fast inference
- Jupyter notebook for analysis and reproducibility
